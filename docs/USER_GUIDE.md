# MEMOIR 使用指南

## 打开手账

双击项目根目录的 `index.html`。选择「逛逛官网」可以体验互动样页、挑选模板；选择「进入手机手账」就能直接开始记录。两页均可独立打开，请保留原有目录结构。

在已打开的浏览器里，手记、任务和心情通过「保存」写入本机。打卡、完成待办和切换纸张即时保存。

## 手机访问

手机端是响应式 Web 应用。在手机浏览器中打开 `mobile_app/index.html` 对应的网址即可使用。屏幕底部显示四个入口，宽屏电脑上相同入口位于左侧。

如需在同一局域网的手机上体验，可在装有 Python 的电脑上打开 PowerShell，执行以下命令。

```powershell
python -m http.server 8000 --directory "D:\antigravity memoir"
```

电脑可访问 `http://localhost:8000/`。手机连接同一 Wi-Fi，访问 `http://电脑局域网IP:8000/mobile_app/`。使用防火墙允许的专用网络，体验完在终端按 Ctrl+C 停止服务。此命令会共享整个项目目录，仅用于受信任的局域网。正式托管时只需发布启动页、website、mobile_app、shared 及需要提供的文档。

## 常用操作

- **日页**　点右上角日期可跳到任意一天，点日期条可切换同一周内的日页。日页显示当日手记、待办、打卡和心情。
- **手账本**　点「写日记」创建记录。可以添加正文、引用、提示、清单和图片块，选择空间、贴纸及和纸胶带。点一张手记卡片进入阅读页，可直接勾选清单。「编辑手记」可修改或删除该篇记录。支持按标题和正文搜索，或按空间筛选。
- **计划**　添加任务时可以指定日期、时间、空间和优先级。点任务名称编辑，点左侧方框切换完成状态。习惯可按日期打卡，再点一次可撤销。
- **心情**　在日页选择心情，调整强度并填写可选标签。到「我的」可查看截至所选日期的七天心情。
- **我的**　切换四种手账用纸、建立空间、导出 JSON 或恢复已有备份。恢复前会显示备份中的记录数量并请求确认。
- **官网**　互动样页供试用。在「试着写一页」输入标题和正文、选择贴纸，点「在手账中继续写」后保存。模板馆支持筛选，选中的模板会在编辑器中生成一篇待保存的新手记。

## 数据存放与迁移

新手账使用浏览器的 `localStorage`，键名为 `memoir.journal.v1`。同一浏览器、同一来源下的记录可以在刷新后继续使用。双击文件、通过 localhost 访问、换端口、换浏览器和换设备，可能会看到不同的数据。直接打开文件时，各浏览器对本地文件存储的处理也有所差异。

换设备或清理浏览器前，在「我的」导出备份。用另一台设备打开手账，在「我的」恢复这份 JSON。图片会缩小后随记录保存，并包含在备份中。如果浏览器提示存储不足，请先导出备份。

## 项目目录

| 位置 | 用途 |
| --- | --- |
| `index.html` | 项目启动页 |
| `website/` | 官网、互动样页、模板馆及官网图片 |
| `mobile_app/` | 手账应用、编辑器、本地数据管理及手机端图片 |
| `shared/` | 两端共用的视觉样式、模板内容和日期工具 |
| `docs/` | 产品规范、视觉体系和使用指南 |
| `tests/browser.cjs` | 浏览器端到端回归测试 |
| `source_repo/` | 已搬入的原始 React/Vite 仓库 |

## 回归测试

使用具备 Node.js、Playwright 和 Chromium 的开发环境运行 `node tests/browser.cjs`。默认测试直接打开本地文件的方式。设置 `MEMOIR_URL` 可测试已启动的静态网站，地址应以斜杠结尾。可用 `MEMOIR_PLAYWRIGHT` 指定已安装的 Playwright 模块路径，并用 `MEMOIR_BROWSER` 指定 Chrome 或 Edge 可执行文件。测试使用独立浏览器上下文。
